# Документация модуля [`triangle.py`](../triangle.py)

## Общее описание
Данный модуль содержит фукнции для вычисления площади и периметра треугольника.

## Функции

### 1. `area(a, h)` - функция для вычесления площади треугольника по его стороне и высоте проведённой к ней.
    
    Параметры:
            a: сторона квадрата
            h: высота которая проведена к этой стороне

    Возвращаемое значение:
            S: площадь круга по формуле: a * h / 2

<br>

Пример вызова:


```python
from triangle import area

print(area(5, 6)) # Выводит: 15.0
```

<br><br><br>

### 2. `perimeter(a, b, c)` - функция для вычесления периметра треугольника по его сторонам.
    
    Параметры:
            a: первая сторона квадрата
            b: вторая сторона квадрата
            c: третья сторона квадрата

    Возвращаемое значение:
            P: периметр круга по формуле a + b + c

<br>

Пример вызова:


```python
from triangle import perimeter

print(perimeter(5, 10, 20)) # Выводит: 35
```

<br><br><br>

## Общий запуск
```python
import triangle


h = int(input('Введите высоту к стороне a: '))
a = int(input('Введите сторону a: '))
b = int(input('Введите сторону b: '))
c = int(input('Введите сторону c: '))


print(f'Его площадь: {triangle.area(a, h)}')
print(f'Его периметр: {triangle.perimeter(a, b, c)}')
```
