# Документация модуля [`square.py`](../square.py)

## Общее описание
Данный модуль содержит фукнции для вычисления площади и периметра квадрата.

## Функции

### 1. `area(a, b)` - функция для вычесления площади квадрата по его стороне.
    
    Параметры:
            a: сторона квадрата

    Возвращаемое значение:
            S: площадь квадрата по формуле: a²

<br>

Пример вызова:


```python
from square import area

print(area(4)) # Выводит: 16
```

<br><br><br>

### 2. `perimeter(a, b)` - функция для вычесления периметра квадрата по его стороне.
    
    Параметры:
            a: сторона квадрата

    Возвращаемое значение:
            P: периметр квадрата по формуле 4a

<br>

Пример вызова:


```python
from square import perimeter

print(perimeter(4)) # Выводит: 16
```

<br><br><br>

## Общий запуск
```python
import square


a = int(input('Введите сторону квадрата: '))

print(f'Его площадь: {square.area(a)}')
print(f'Его периметр: {square.perimeter(a)}')
```
