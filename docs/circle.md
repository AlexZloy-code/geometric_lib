# Документация модуля [`circle.py`](../circle.py)

## Общее описание
Данный модуль содержит фукнции для вычисления площади и периметра круга.

## Функции

### 1. `area(r)` - функция для вычесления площади круга по его радиусу.
    
    Параметры:
            r: радиус круга

    Возвращаемое значение:
            S: площадь круга по формуле: πR²

<br>

Пример вызова:


```python
from circle import area

print(area(5)) # Выводит: 78.53981633974483
```

<br><br><br>

### 2. `perimeter(r)` - функция для вычесления периметра круга по его радиусу.
    
    Параметры:
            r: радиус круга

    Возвращаемое значение:
            P: периметр круга по формуле 2πR 

<br>

Пример вызова:


```python
from circle import perimeter

print(perimeter(5)) # Выводит: 31.4159265358979
```

<br><br><br>

## Общий запуск
```python
import circle


r = input('Круг радиуса :')

print(f'Его площадь: {circle.area(r)}')
print(f'Его периметр: {circle.perimeter(r)}')
```
