# Документация модуля [`rectangle.py`](../rectangle.py)

## Общее описание
Данный модуль содержит фукнции для вычисления площади и периметра прямоугольника.

## Функции

### 1. `area(a, b)` - функция для вычесления площади прямоугольника по его сторонам.
    
    Параметры:
            a: первая сторона прямоугольника
            b: вторая (смежная с первой) сторона пряямоугольника

    Возвращаемое значение:
            S: площадь прямоугольника по формуле: ab

<br>

Пример вызова:


```python
from rectangle import area

print(area(4, 8)) # Выводит: 32
```

<br><br><br>

### 2. `perimeter(a, b)` - функция для вычесления периметра прямоугольника по его сторонам.
    
    Параметры:
            a: первая сторона прямоугольника
            b: вторая (смежная с первой) сторона пряямоугольника

    Возвращаемое значение:
            P: периметр прямоугольника по формуле 2a + 2b 

<br>

Пример вызова:


```python
from rectangle import perimeter

print(perimeter(4, 8)) # Выводит: 24
```

<br><br><br>

## Общий запуск
```python
import rectangle


a = int(input('Введите сторону a: '))
b = int(input('Введите сторону b: '))

print(f'Его площадь: {rectangle.area(a, b)}')
print(f'Его периметр: {rectangle.perimeter(a, b)}')
```
